Prism Team Instance

Tải lên một ZIP Export instance từ Prism Launcher. Launcher của team sẽ tải gói mới nhất, nhập thành instance mới và lưu trong thư mục PrismLauncherTeam\instances.

Host cũng tự quét ZIP mới nhất trong thư mục server/packs. Có thể chép trực tiếp một file ZIP vào đó; không cần tạo file metadata đi kèm.

Đang kiểm tra ZIP mới nhất…
Mã upload chỉ được giữ tạm trong trang này và gửi tới máy chủ.
